# mceca (Python library)

The Python half of [MC-ECA](../README.md). It connects to the MC-ECA Minecraft mod
and lets you control an NPC: `say`, `look_at`, `gesture`, `thinking`, and react to
chat with `@npc.on_chat`.

Install (from the repository root):

```bash
pip install -e python
```

See [docs/03-api-reference.md](../docs/03-api-reference.md) for the full API.
